# Code of Conduct

## The short version

Be decent. Assume good faith. Critique the code, not the person.

## Scope

This applies to issues, pull requests, commit messages, and any other project
space.

## Expected

- Direct, specific technical criticism. "This query is O(n) per row and will not
  scale" is welcome. "This is stupid" is not.
- Patience with the fact that this project is unmaintained; nobody owes you a
  response.
- Grace when you are told a change will not be merged.

## Not acceptable

- Harassment, insults, or personal attacks.
- Discriminatory language or imagery, including in usernames.
- Publishing others' private information without consent.
- Sustained disruption of discussion.

## Enforcement

The maintainer may edit, lock, or delete any contribution, and may block any
account, for behaviour that violates this. Because the project is unmaintained,
expect enforcement to be slow and final rather than conversational.

Report problems through a private security advisory on this repository.
